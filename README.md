# ترمینال هوشمند مدیریت ثروت (نسخه امن، ماژولار و بدون سرور واسط)

داشبورد شخصی، آفلاین-اول (PWA) و راست‌به‌چپ برای مدیریت یکپارچه سبد **بورس ایران، رمزارز، استیبل‌کوین، NFT تلگرام و مهندسی وام** که بدون نیاز به ابزار Build مستقیماً روی **GitHub Pages** اجرا می‌شود.

---

## ۱. معماری جدید حریم خصوصی و امنیت

1. **حذف کامل `portfolio.json` از ریپازیتوری عمومی**:
   - اطلاعات شخصی شما (تعداد سهام، میانگین خرید، موجودی نقد بانکی/کارگزاری، کلکسیون NFT و جزئیات وام) **فقط در `localStorage` مرورگر شما** نگهداری می‌شوند.
   - برای انتقال بین دستگاه‌ها یا پشتیبان‌گیری، از دکمه **«دانلود فایل بکاپ JSON»** و **«بارگذاری فایل بکاپ JSON»** (مجهز به اعتبارسنجی ساختار `validateAndSanitizePortfolioJson`) در مودال تنظیمات استفاده کنید.
2. **جایگزینی با `data/symbols.json` و `data/alerts.json`**:
   - اسکریپت پایتون (`scripts/update_prices.py`) دیگر هیچ نیازی به دارایی‌های شما ندارد و فقط فهرست کدهای نمادها را از `data/symbols.json` می‌خواند و قیمت‌های روز را در `data/prices.json` می‌نویسد.
   - قوانین هشدار قیمتی غیرحساس در `data/alerts.json` تعریف می‌شوند تا در صورت فعال شدن شرط در GitHub Actions، پیام تلگرام ارسال گردد.
3. **حذف کلید لو رفته `BrsApi` از کلاینت و سورس‌کد**:
   - کلید `BrsApi` به طور کامل از `index.html` و `scripts/update_prices.py` حذف شده است.
   - قیمت‌گیری مستقیم از مرورگر با کلید خصوصی ممنوع است؛ اسکریپت بک‌اند کلید جدید را صرفاً از متغیر محیطی `BRS_API_KEY` در **GitHub Secrets** می‌خواند.
4. **محافظت در برابر XSS و مخفی‌سازی کامل**:
   - تمام داده‌های متنی (یادداشت‌ها، نام دارایی، نام NFT و داده‌های Import شده) پیش از قرارگیری در `innerHTML` از تابع `escapeHtml` عبور می‌کنند.
   - حالت مخفی‌سازی ارقام (`privacy-masked`) علاوه بر کارت‌ها و جداول، **Tooltip نمودارها، محورهای Y/X در Chart.js و فیلدهای Input قیمت خرید** را نیز می‌پوشاند. همچنین امکان تعریف **قفل PIN چهار رقمی** در تنظیمات فراهم شده است.

## ۳. راهنمای تنظیم GitHub Secrets و اجرای اسکریپت

در مخزن گیت‌هاب خود به مسیر **Settings > Secrets and variables > Actions** بروید و سه Secret زیر را ایجاد کنید:

| نام Secret | کاربرد |
| :--- | :--- |
| `BRS_API_KEY` | کلید جدید دریافتی از پنل BrsApi.ir (پس از ابطال کلید قبلی) |
| `TELEGRAM_BOT_TOKEN` | توکن ربات تلگرام دریافتی از `@BotFather` برای ارسال هشدارهای قیمتی |
| `TELEGRAM_CHAT_ID` | شناسه عددی اکانت یا کانال تلگرام شما (قابل دریافت از `@userinfobot`) |

### اجرای دستی و تست محلی اسکریپت پایتون
```bash
export BRS_API_KEY="YOUR_NEW_BRS_KEY"
export TELEGRAM_BOT_TOKEN="YOUR_BOT_TOKEN"
export TELEGRAM_CHAT_ID="YOUR_CHAT_ID"
python3 scripts/update_prices.py
```

### بازتولید آیکن‌های PNG از روی SVG (در صورت تغییر لوگو)
اگر فایل `icons/icon.svg` را ویرایش کردید، می‌توانید با ابزار `rsvg-convert` یا اسکریپت پایتون (Pillow) آیکن‌ها را بازسازی کنید:
```bash
rsvg-convert -w 192 -h 192 icons/icon.svg -o icons/icon-192.png
rsvg-convert -w 512 -h 512 icons/icon.svg -o icons/icon-512.png
```

## نسخه بازطراحی‌شده — Premium Emerald

- لایه طراحی جدید در `css/premium-overrides.css` با پالت ذغالی/زمردی، کنتراست بهتر، حالت واکنش‌گرای موبایل و پشتیبانی از `prefers-reduced-motion`.
- متادیتای توصیفی، رنگ تم نصب و پیوند پرش به محتوای اصلی برای دسترس‌پذیری.
- نسخه جدید کش سرویس‌ورکر برای جلوگیری از باقی‌ماندن CSS قبلی پس از انتشار.
- اعتبارسنجی داده‌های عمومی بازار با `python scripts/validate_data.py` و اجرای آن در گردش‌کار قیمت‌ها. تغییر روزانه غیرعادی باید صریحاً با `suspect: true` علامت بخورد.
- توضیح شفاف‌تر درباره PIN: این قفل صرفاً مانع مشاهده عادی در مرورگر است و رمزگذاری داده‌ها یا جایگزین امنیت دستگاه محسوب نمی‌شود.

### نکته مهم درباره داده‌های بازار

اعتبارسنجی ساختار، صحت واقعی قیمت را تضمین نمی‌کند. هر قیمت مشکوک، کهنه یا بدون منبع قابل اتکا باید پیش از تصمیم مالی بررسی شود. مقادیر `data/prices.json` داده عمومی بازار هستند؛ هیچ اطلاعات سبد شخصی، بکاپ یا کلید API نباید به مخزن عمومی اضافه شود.
